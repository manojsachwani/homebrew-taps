# Homebrew taps

Homebrew casks for my tools.

```sh
brew install manojsachwani/taps/bearty
brew install manojsachwani/taps/deadwood
```

| Cask | What it is |
| --- | --- |
| [bearty](https://github.com/manojsachwani/bearty) | Terminal UI for building custom themes for the Bear notes app (macOS) |
| [deadwood](https://github.com/manojsachwani/deadwood) | Terminal UI for clearing out git branches and worktrees |

The files in `Casks/` are generated by each project's release workflow; changes made here by hand are overwritten on the next release.
